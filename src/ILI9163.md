# ILI9163C – Raspberry Pi Pico C++ Driver

A clean, zero-dependency hardware-SPI driver for the **ILI9163C** 128×128 TFT
display controller, written in modern C++17 for the **Raspberry Pi Pico** SDK.

---

## Features

| Category | Details |
|---|---|
| **Interface** | Hardware SPI (SPI0 or SPI1), up to 62.5 MHz |
| **Colour depth** | RGB565 (16-bit) |
| **Primitives** | Pixel, H/V line, line, rect, filled rect, circle, filled circle, triangle, filled triangle, rounded rect |
| **Bitmaps** | Raw RGB565 frame push with chunked DMA-friendly burst writes |
| **Text** | Fixed-width bitmap font system; bundled 5×7 ASCII font |
| **Rotation** | 0 / 90 / 180 / 270° via MADCTL |
| **Extras** | Hardware reset, sleep/wake, display on/off, backlight GPIO, display inversion |

## Wiring

| Display pin | Pico GPIO | Notes |
|---|---|---|
| MOSI / SDA  | GP19 | SPI0 TX |
| SCLK / SCL  | GP18 | SPI0 SCK |
| CS / CE     | GP17 | Active-low chip-select |
| DC / RS     | GP16 | High = data, Low = command |
| RST / RESET | GP20 | Active-low reset (optional) |
| BL / LED    | GP15 | Backlight (optional) |
| VCC         | 3.3 V | |
| GND         | GND | |

You can use different GPIOs — just pass them to the constructor.

## Quick Start

### 1. Add to your project

Copy `ili9163c.hpp`, `ili9163c.cpp` (and optionally `font5x7.hpp`) into your
project source tree, then add to your `CMakeLists.txt`:

```cmake
add_library(ili9163c STATIC ili9163c.cpp)
target_include_directories(ili9163c PUBLIC .)
target_link_libraries(ili9163c PUBLIC pico_stdlib hardware_spi hardware_gpio)

# link against your executable
target_link_libraries(my_app ili9163c)
```

### 2. Include and initialise

```cpp
#include "ili9163c.hpp"
#include "font5x7.hpp"

// Construct with SPI peripheral + GPIO pins
ILI9163C tft(spi0,
             /*sck*/  18,
             /*mosi*/ 19,
             /*cs*/   17,
             /*dc*/   16,
             /*rst*/  20,  // pass 0xFF to skip hardware reset
             /*bl*/   15,  // pass 0xFF to skip backlight GPIO
             32'000'000u); // SPI speed in Hz (optional, default 32 MHz)

int main() {
    stdio_init_all();
    tft.begin();          // init SPI, GPIO, send init sequence, clear screen
    tft.setBacklight(true);
    // ... draw!
}
```

## API Reference

### Lifecycle

```cpp

```

### Configuration

```cpp
void setRotation(Rotation r);  // Rotation::Deg0 / Deg90 / Deg180 / Deg270

int16_t height();              // Logical height (respects rotation)
```

## Custom Fonts

Implement your own `Font` by filling in the descriptor:

```cpp
struct Font {
    const uint8_t* data;   // Glyph bitmap: height rows × ceil(width/8) bytes
    uint8_t        width;  // Pixels wide (fixed)
    uint8_t        height; // Pixels tall
    uint8_t        first;  // First ASCII codepoint stored
    uint8_t        count;  // Number of consecutive glyphs
};
```

Each glyph row is stored as one or more bytes, MSB = leftmost pixel.
See `font5x7.hpp` for a complete worked example (95 glyphs, 5×7 px).

---

## Performance Notes

* `fillRect` / `fillScreen` use a 64-word burst write loop — a full 128×128
  screen clear takes roughly **0.8 ms** at 32 MHz SPI.
* `drawBitmap` sends raw words in 64-word chunks; a full-screen 128×128
  bitmap push takes about **3.2 ms** at 32 MHz.
* Increase `spi_speed` up to ~62.5 MHz (the Pico's SPI0 maximum at 125 MHz
  system clock) for faster throughput if your display and PCB allow it.
